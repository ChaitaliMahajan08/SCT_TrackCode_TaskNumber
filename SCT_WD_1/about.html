About SkillCraft Technology

SkillCraft Technology runs structured internships in software and web development. Interns complete numbered tasks, receive feedback, and build a portfolio of working projects.

Hands-on tasks

Each task has a clear brief — this one is a responsive landing page with an interactive, fixed menu.

Guided practice

Mentors review submissions so interns improve layout, interaction, and code quality over the program.

Portfolio ready

Finished tasks can be shared as live sites, which is how this project is meant to be submitted.
